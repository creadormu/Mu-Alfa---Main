OPTION A: Disable precompiled headers for new files
----------------------------------------------------

For each of my new files:

1. Right-click FPSManagerHook.cpp in Solution Explorer
2. Properties
3. C/C++ → Precompiled Headers
4. Precompiled Header: Select "Not Using Precompiled Headers"
5. Click OK

Repeat for:
  - AdvancedFPSManager.cpp
  - ImprovedHackCheck.cpp
  - OptimizedShaders.cpp
  - FPSManagerHook.cpp

Then rebuild.

--------------------------------

Make sure your project has:

    #define WIN32_LEAN_AND_MEAN
    #include <windows.h>
    #include <gl/GL.h>
    #include <stdio.h>

stdafx.cpp:
