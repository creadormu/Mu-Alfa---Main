PROBLEM: Compile error "AdvancedFPSManager.h not found"

PROBLEM: Crash on startup
--------------------------
SOLUTION: Check initialization order
   - gAdvancedFPSManager.Initialize() must be called BEFORE
     the game loop starts
   - Currently at Main.cpp line 393


PROBLEM: FPS still at 16-18
----------------------------
SOLUTION A: Check config file
   - Make sure LimitFPS = 60 in CreadorDeMU

SOLUTION B: Hardcode for testing

PROBLEM: Character moves too fast
----------------------------------
SOLUTION: Frame multiplier not applied
   - Check User.cpp line 61 has:
     float frameMultiplier = gAdvancedFPSManager.GetFrameMultiplier();
   - Check User.cpp lines 69, 70, 75, 76 have:
     * frameMultiplier at the end


PROBLEM: Character moves too slow
----------------------------------
SOLUTION: Wrong FPS calculation
   - Add debug output (see TEST 2 above)
   - Check what FPS and multiplier values are
   - If multiplier > 1.0, something is wrong


PROBLEM: Stuttering/jittering
------------------------------
SOLUTION: Enable VSync
   - Add this to Main.cpp after initialization:
     gAdvancedFPSManager.SetVSync(true);
