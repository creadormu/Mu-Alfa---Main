================================================================================
          🔧 FIX FOR CHARACTER SELECT FREEZE - MANUAL STEPS
================================================================================

PROBLEM:
--------
Game compiles and runs, but freezes at "loading..." after login.
Character selection screen never appears.

ROOT CAUSE:
-----------
gAdvancedFPSManager.Update() was only in User::Refresh(), which is NOT called
during login or character selection! The FPS manager never updates, causing
the game to freeze.

SOLUTION:
---------
Hook the main rendering loop (0x004DA2AC) which is called EVERY frame in ALL
game states (login, character select, gameplay, etc.)

================================================================================
                        WHAT THE HOOK DOES
================================================================================

FPSManagerHook.cpp creates a detour at address 0x004DA2AC:

Original flow:
  0x004DA2AC: [Original instruction]  → Continue game loop

New flow with hook:
  0x004DA2AC: JMP to FPSManagerHookFunction
               ↓
              Save registers (pushad/pushfd)
               ↓
              gAdvancedFPSManager.Update()  ← Update FPS timing
               ↓
              Restore registers (popfd/popad)
               ↓
              Execute original instruction
               ↓
              Return to game loop

This ensures FPS manager updates in EVERY frame, regardless of game state!
