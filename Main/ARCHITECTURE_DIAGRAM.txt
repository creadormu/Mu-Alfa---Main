FPS COMPARISON:
---------------

Original System (25 FPS):
┌────┬────┬────┬────┬────┬────┬────┬────┬─── 
│ 40 │ 40 │ 40 │ 40 │ 40 │ 40 │ 40 │ 40 │ ...  ← Frame time (ms)
└────┴────┴────┴────┴────┴────┴────┴────┴───
 Frame times: All 40ms
 Frames per second: 1000/40 = 25 FPS
 Movement per frame: 4 units
 Total movement per second: 25 * 4 = 100 units

New System (60 FPS):
┌──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──
│16│16│16│16│16│16│16│16│16│16│16│16│16│16│16│16│16│ ...
└──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──┴──
 Frame times: All ~16.67ms
 Frames per second: 1000/16.67 = 60 FPS
 Movement per frame: 4 * 0.417 = 1.67 units
 Total movement per second: 60 * 1.67 = 100 units ← SAME!

Visual smoothness: 
25 FPS: ●─────●─────●─────●─────●      (choppy)
60 FPS: ●──●──●──●──●──●──●──●──●      (smooth!)


MEMORY LAYOUT:
--------------

Original HackCheck:
┌──────────────────────────────────┐
│ Address: 0x004DA3E0              │
│ Value: 0x28 (40 decimal = 40ms)  │ ← Hardcoded!
│ Purpose: Frame time limit        │
└──────────────────────────────────┘

Our System:
┌──────────────────────────────────┐
│ Variable: g_DynamicFPSLimit      │
│ Value: 16 (for 60 FPS)           │ ← Configurable!
│        8 (for 120 FPS)           │
│        40 (for 25 FPS original)  │
│ Purpose: Dynamic frame limit     │
└──────────────────────────────────┘

Speed Modifiers (Monitored by HackCheck):
┌────────────────────────────────────────┐
│ SpeedModifier1: Viewport[0x214]        │ ← Not modified!
│ SpeedModifier2: Viewport[0x218]        │ ← Not modified!
│ ModelModifier1: Viewport[0x31A]        │ ← Not modified!
│ ModelModifier2: Viewport[0x394]        │ ← Not modified!
│ ModelModifier3: Viewport[0x398]        │ ← Not modified!
└────────────────────────────────────────┘
These stay the same → No hack detection!

Our Math (Not in memory, just calculation):
┌────────────────────────────────────────┐
│ frameMultiplier = DeltaTime / 40       │ ← Calculated!
│ scaledSpeed = originalSpeed * multiplier│ ← Applied!
└────────────────────────────────────────┘
Memory not modified → Safe!

DECISION FLOW:
--------------

Start
  │
  ▼
Read config LimitFPS
  │
  ├─► 60? → g_DynamicFPSLimit = 16 (0x10)
  ├─► 120? → g_DynamicFPSLimit = 8 (0x08)
  ├─► 25? → g_DynamicFPSLimit = 40 (0x28)
  └─► Other? → Calculate appropriate value
      │
      ▼
Each frame:
  │
  ├─► Calculate deltaTime
  ├─► Calculate frameMultiplier
  ├─► Update game logic with scaled values
  ├─► Render
  └─► HackCheck validates timing
      │
      ├─► If elapsed < limit: Sleep(difference)
      └─► If speed modifiers changed: ExitProcess()

-------------------
