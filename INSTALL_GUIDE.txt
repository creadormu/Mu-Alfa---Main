  HIGH FPS MOD - INSTALLATION GUIDE
  60 FPS / 120 FPS Support with OpenGL Shader Enhancement
═══════════════════════════════════════════════════════════════════════════════

REQUIREMENTS:
═════════════
- glew32.dll (OpenGL Extension Wrangler Library)
- VSyncLib.GLIB (VSync Control Library)
- OpenGL 2.0+ Compatible Graphics Card

INSTALLATION STEPS:
═══════════════════
1. COPY FILES TO CLIENT DIRECTORY:
   ┌─────────────────────────────────────────────────────────────────────────┐
   │ Copy the following files to your game client root folder:              │
   │                                                                         │
   │ - glew32.dll                (OpenGL Extensions)                        │
   │ - VSyncLib.GLIB             (VSync Control)                            │
   │ - Main.dll                  (Updated client with FPS selector)         │
   │ - MainInfo.ini              (Updated configuration)                    │
   └─────────────────────────────────────────────────────────────────────────┘

2. CREATE SHADERS FOLDER:
   ┌─────────────────────────────────────────────────────────────────────────┐
   │ Create a "Shaders" folder in your client root directory and copy:     │
   │                                                                         │
   │ Shaders\                                                                │
   │   ├── vertexshader.vs       (Vertex Shader - GLSL 1.20)               │
   │   └── vertexfragment.fs     (Fragment Shader - GLSL 1.20)             │
   └─────────────────────────────────────────────────────────────────────────┘

3. CONFIGURE MainInfo.ini:
   ┌─────────────────────────────────────────────────────────────────────────┐
   │ Edit MainInfo.ini and ensure these settings:                           │
   │                                                                         │
   │ MonitorFPS = 1              (Enable FPS monitoring)                    │
   │ MonitorMS = 1               (Enable MS monitoring)                     │
   │ LimitFPS = 17               (Default to 60 FPS mode)                   │
   │                                                                         │
   │ Note: LimitFPS will be overridden by the dialog selection on startup  │
   └─────────────────────────────────────────────────────────────────────────┘

4. LAUNCH THE GAME:
   ┌─────────────────────────────────────────────────────────────────────────┐
   │ When you start the game, a dialog box will appear asking you to       │
   │ select your preferred FPS mode:                                        │
   │                                                                         │
   │ [YES]    = 60 FPS  (Recommended - Smooth gameplay)                    │
   │ [NO]     = 40 FPS  (Default - Best compatibility)                     │
   │ [CANCEL] = 120 FPS (High Performance - Requires powerful GPU)         │
   │                                                                         │
   │ OpenGL Shaders will be automatically loaded for enhanced graphics     │
   └─────────────────────────────────────────────────────────────────────────┘

TROUBLESHOOTING:
════════════════
Problem: Dialog doesn't appear
Solution: Make sure Main.dll is in the correct directory and MainInfo.ini is configured properly

Problem: FPS still locked at 26
Solution: 
  1. Check that glew32.dll and VSyncLib.GLIB are in the client folder
  2. Verify Shaders folder exists with both .vs and .fs files
  3. Try running as Administrator

Problem: Graphics look wrong
Solution:
  1. Update your graphics drivers
  2. Ensure your GPU supports OpenGL 2.0+
  3. Check shader files are not corrupted

Problem: Low performance at 120 FPS
Solution: 
  1. Select 60 FPS mode instead (recommended for most systems)
  2. Update graphics drivers
  3. Close background applications
  4. Enable VSync in MainInfo.ini
